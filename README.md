## Deploy to GitHub Pages

This repository is a self-contained static site. The GitHub Actions workflow in
`.github/workflows/pages.yml` deploys it automatically whenever changes are
pushed to `main`.

After pushing the repository:

1. Open **Settings > Pages** on GitHub.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Open the **Actions** tab and wait for **Deploy to GitHub Pages** to finish.
4. Use the URL shown in the workflow summary.

The presentation is served from [`index.html`](./index.html).
